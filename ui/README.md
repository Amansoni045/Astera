# Astera UI — Next.js App Router Frontend

This directory contains the Next.js frontend for **Astera**, built with React 19, TypeScript, Tailwind CSS, Auth.js (NextAuth v5), and Prisma ORM.

Please refer to the main [Root README](../README.md) for full project documentation, architecture, and setup instructions.

## Development Scripts

```bash
# Run local development server
npm run dev

# Generate Prisma Client
npm exec prisma generate

# Create production build
npm run build
```
