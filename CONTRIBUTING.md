# Contributing to Astera

Thank you for your interest in contributing to **Astera**! We welcome contributions from developers of all skill levels.

## How to Contribute

1. **Fork the Repository**: Create your own copy of Astera on GitHub.
2. **Clone Locally**:
   ```bash
   git clone https://github.com/your-username/Astera.git
   cd Astera
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Install Dependencies**:
   - Backend: Set up a Python 3.11+ virtual environment and install `requirements.txt`.
   - Frontend: Navigate to `ui/` and run `npm install`.
5. **Commit Your Changes**: Follow clear, descriptive commit messages.
6. **Push and Open a Pull Request**: Submit your PR against `main`.

## Code Style Guidelines
- **TypeScript / React**: Use Next.js App Router idioms, standard hooks, and Tailwind CSS. Ensure `npm run build` passes cleanly.
- **Python Backend**: Follow standard PEP8 guidelines and type hints.

## Code of Conduct
Please ensure all discussions, issues, and PR comments remain respectful, inclusive, and professional.
